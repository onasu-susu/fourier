フーリエ級数で音をつくる

係数を入れると、波形が見えて、その音が聴けます。

f(x) = a02 + nΣk=1 ( ak coskπxL + bk sinkπxL )

x を時間（秒）として聴きます。周期は 2L 秒、基本の音の高さは f₀ = 1/(2L) Hz です。

式の書き方
  • k（1 から n まで順に入ります）、n、pi（円周率）、e が使えます。
  • + − * / ^ と、カッコ ( )。かけ算は 2*k のように * を書きます（2k は不可）。
  • 関数：sin cos tan sqrt abs exp ln log floor ceil round sign（例：sin(k)）
  • mod(a,b)：a を b で割った余り。mod(k,2) は k が奇数なら 1、偶数なら 0 です。
  • eq(a,b)：a と b が等しければ 1、ちがえば 0。eq(k,3) は k=3 のときだけ 1 です。
  • min(a,b)・max(a,b)。(-1)^k は k が偶数なら 1、奇数なら −1 です。
  • 例：1/k、1/k^2、2*(-1)^(k+1)/(k*pi)、0.5^k

② 聴く

鳴らしている間に入力を変えると、すぐ音が変わります。音量は小さめから上げてください。

③ 波形（x が −2L 〜 2L の 2 周期）

a₀ は直流成分（平均の高さ）です。耳には聞こえないので、音は変わらず、波形の上下の位置だけが変わります。
